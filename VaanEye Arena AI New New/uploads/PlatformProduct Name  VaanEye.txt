What is VaanEye?VaanEye (The Eye in the Sky): 

An all-in-one, next-generation Geo-Intelligence platform that acts as a single virtual eye monitoring Earth from space.

The Concept: It harnesses 100% free, open-source satellite data to solve multi-domain problems across Land, Water, Sky, and Human Safety simultaneously.

The "One App, One Purpose" Limitation: Current technologies are isolated. 

Users have to use one app for agriculture, another for ocean status, and different websites for fire/flood alerts.

Actionable Intelligence: Automatically converts raw geospatial datasets into simple native language mobile alerts (SMS/Push) for common citizens.

🛠️ SLIDE 3: TECHNICAL APPROACH & ADVANCED IMAGE ANALYTICS (SIH PPT Formatting)

This expanded technical slide focuses on heavy image/video analytics, database tracking, and spatial data comparisons.markdown### **1. CORE DEVELOPMENT ENVIRONMENT (The Full MERN + Next.js Stack)**
* **Frontend UI (Next.js & React.js):** Hosted on Vercel. Renders dynamic map dashboards using **Mapbox GL JS / Leaflet.js** for interactive vector layer caching.
* **Backend Engine (Node.js & Express.js):** Scaled on dedicated cloud instances (Render/AWS). Acts as the primary API broker, handling asynchronous user triggers, geolocation parsing, and dispatch webhooks.
* **Dual Database Architecture (Supabase + Firebase):**
    * **Supabase (PostgreSQL + PostGIS):** Uses robust spatial indexing (`R-Tree`) to store crop/land polygons and run instant intersection queries (e.g., matching coordinates against flood zones).
    * **Firebase:** Manages user authentication sessions and powers real-time dashboard notification alerts.

### **2. HEAVY IMAGE PROCESSING & COMPUTER VISION (Python Pipeline)**
* **Geospatial Processing Engine (GDAL, Rasterio, Fiona):** Used to read, crop, clean, and align raw multi-spectral satellite image files (.TIFF formats) with specific coordinate maps.
* **Matrix Analytics Engine (NumPy & SciPy):** Converts satellite pixel values into actionable mathematical indexes (NDVI for crop stress, NDWI for flood staging).
* **Computer Vision Framework (PyTorch & OpenCV):**
    * **Temporal Change Detection:** Runs image-differencing scripts that compare yesterday's matrix coordinates with fresh satellite feeds to flag sudden structural land adjustments or encroachments.
    * **Thermal Deep Learning Models:** Runs lightweight Convolutional Neural Networks (CNNs) across Shortwave Infrared (SWIR) bands to detect immediate thermal anomalies (wildfires).
